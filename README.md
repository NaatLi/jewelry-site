# Эксклюзив

Сайт-витрина ювелирного магазина «Эксклюзив» — статический интернет-проект для демонстрации каталога украшений, фильтрации товаров по категориям и просмотра карточки товара.

## О проекте

Проект представляет собой адаптивную витрину ювелирных изделий из золота и серебра. На сайте есть:

- главная страница с приветственным блоком и преимуществами магазина;
- каталог украшений с фильтрацией по категориям;
- карточки товаров с информацией о материале, весе, размере и цене;
- отдельная страница товара с галереей изображений;
- мобильное меню и плавная прокрутка по разделам;
- контактная информация: телефон, Telegram, WhatsApp, Max.

## Технологии

- HTML5
- CSS3
- JavaScript
- статические изображения

Проект не использует backend, базы данных и сборщики проектов. Это обычный статический сайт, который можно открыть напрямую в браузере или запустить через локальный веб-сервер.

## Запуск проекта

### Вариант 1: открыть напрямую

Откройте файл `index.html` в браузере.

### Вариант 2: запустить локальный сервер

Из корня проекта выполните:

```bash
python -m http.server 8000
```

После этого откройте в браузере:

```text
http://localhost:8000/
```

## Основные страницы

- `index.html` — главная страница магазина;
- `catalog.html` — каталог с фильтрами по категориям;
- `product.html` — детальная страница товара.
